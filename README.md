# Remove Context Menu Items

## Contributing

Any help with translating this Windhawk mod is greatly appreciated! Since localization is a very time-consuming process and I’m currently at capacity with development, I won't be able to add further languages on my own. I'm relying on the community to help expand our reach. 

Contributors will be credited and mentioned within the mod.

### Why GitHub?
I’ve decided to manage all translations directly through GitHub rather than using external tools. While I considered options like Google Sheets, GitHub is simply more secure and keeps everything organized alongside the code. It also allows us to avoid the high costs of professional translation platforms while keeping the project open and transparent.

### How to Submit Changes / New Language support
If you find a mistake or want to bring the mod to your native language, use the **Translation Helper**. You don't need to fork the repository, edit files, or open a pull request yourself. You only need a free GitHub account.

1. **Open the [Translation Helper](https://armaninyow.github.io/Remove-Context-Menu-Items/).**
2. **Choose your language:**
   * *New language:* type the language and region, for example `Español (México)`.
   * *Fixing or updating a language:* pick it from the dropdown. Its current translations will load automatically.
3. **Fill in the translations** next to each English item. You need to fill in at least one.
4. Click **Submit Translation on GitHub**. A GitHub page opens with everything already filled in. Sign in to GitHub if asked.
5. Click **Create**.

That's it! A pull request is created automatically from your submission, and I'll review and merge it. Your contribution is credited to your GitHub account.

*Note: To find your exact language string, check **Settings > Time & Language > Language & Region** in Windows.*
